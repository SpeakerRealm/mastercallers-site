# MasterCallers site (draft)

Linear-inspired static site for MasterCallers.

**To make live on GitHub Pages:**
1. Go to https://github.com/SpeakerRealm/mastercallers-site/settings/pages
2. Under Build and deployment, select Source: Deploy from a branch
3. Branch: main, folder: / (root)
4. Save

Once enabled, the site will be at:
https://speakerrealm.github.io/mastercallers-site/
